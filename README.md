# Hudson Smith - Portfolio

Welcome to the source code for my personal portfolio website. This project serves as a digital resume, a showcase of my engineering projects, and a collection of my thoughts and reading list.

## 🚀 Built With

This website is a modern static site built using the following technologies:

*   **[Next.js](https://nextjs.org/)**: The React framework for the web, enabling server-side rendering and static site generation.
*   **[Nextra](https://nextra.site/)**: A framework on top of Next.js that allows for writing content in MDX (Markdown + React), making it incredibly easy to maintain content-heavy pages like the Reading List and Portfolio.
*   **[React](https://reactjs.org/)**: For building interactive UI components.
*   **CSS**: Custom styling for the unique postcard loading animation and responsive layouts.

## ✨ Vibe Coding

This project is a product of "Vibe Coding"—a development philosophy prioritizing flow state, creativity, and the leverage of modern AI tools.

Instead of getting bogged down in boilerplate or repetitive tasks, I utilized AI coding assistants (like Gemini) to:
*   Rapidly prototype UI ideas (like the floating envelope animation).
*   Troubleshoot complex dependency issues.
*   Refine styles and layouts efficiently.

It represents a side project built for the joy of creation, blending technical engineering with creative expression.

## 🛠️ Maintenance & Deployment

This project is deployed and maintained using **[Vercel](https://vercel.com/)**.

*   **Continuous Deployment**: Every push to the `main` branch automatically triggers a build and deployment on Vercel, ensuring the live site is always up to date.
*   **Performance**: Vercel's edge network ensures fast load times globally.

## 📦 Running Locally

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
4.  Open http://localhost:3000 with your browser.
