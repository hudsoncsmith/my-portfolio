<div style={{ maxWidth: '1000px', margin: '0 auto', padding: '0 2rem 4rem' }}>
  <h2 style={{ fontSize: '1.8rem', color: '#0056b3', borderBottom: '2px solid #e0e0e0', paddingBottom: '0.5rem', marginBottom: '1.5rem' }}>Project Overview</h2>
  <p style={{ fontSize: '1.1rem', lineHeight: '1.8', marginBottom: '2rem', color: '#333' }}>
As project lead on this government-funded R&D deployment, I directed the effort to upgrade an existing mobile cold spray trailer system to introduce basic autonomy for aircraft maintenance and repair operations in support of fleet readiness. I led an intern team on tooling and mount design for the end effector, and directed adaptation of the scan-and-plan software stack for the cold spray process. The goals were to remove personnel from a hazardous spray environment, improve process consistency, and increase first-pass yield, while working within the constraints of a legacy hydraulic robot and control system already integrated into the trailer.
  </p>

  <h2 style={{ fontSize: '1.8rem', color: '#0056b3', borderBottom: '2px solid #e0e0e0', paddingBottom: '0.5rem', marginBottom: '1.5rem' }}>Key Contributions</h2>
  <ul style={{ fontSize: '1.1rem', lineHeight: '1.8', marginBottom: '2rem', color: '#333', paddingLeft: '1.5rem' }}>
    <li style={{ marginBottom: '1rem' }}><strong>Precision Camera Mount Design:</strong> Led an intern team to design a precision mount for the structured-light camera, using locating pins and toleranced fits to ensure repeatable placement on the end effector across removal and reattachment cycles.</li>
    <li style={{ marginBottom: '1rem' }}><strong>Dual-Nozzle Mounting Scheme:</strong> Directed the design of a mounting scheme to accommodate the customer's two separate cold spray nozzles on the same end effector, maintaining consistent alignment and standoff for both tools.</li>
    <li style={{ marginBottom: '1rem' }}><strong>Vision & Mounting Iteration:</strong> Iterated the structured-light camera mount from a pin-and-thumbscrew prototype to a finalized quick-clip, dual-locator-pin design validated for repeatability.</li>
    <li style={{ marginBottom: '1rem' }}><strong>Scan-to-Path Pipeline:</strong> Adapted the scan-and-plan software stack to detect operator-marked spray regions using color and geometry, generate reachable toolpaths respecting joint limits, and plan configurable hatch patterns and standoff distances for spray coverage.</li>
    <li style={{ marginBottom: '1rem' }}><strong>Safety System Integration:</strong> Integrated the robotic system with the trailer's existing safety architecture so it correctly paused on E-stop or light curtain events and required operator resumption via the system HMI.</li>
    <li style={{ marginBottom: '1rem' }}><strong>Surrogate Material Validation:</strong> Designed a 3D-printed surrogate spray nozzle to validate coverage using colored sand in place of live cold spray material, achieving 100% coverage within taped target regions during testing.</li>
  </ul>
